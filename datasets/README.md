# Handoff report — dataset Vs30 / HVSR Indonesia

**Status per 16 September 2026.** Dokumen ini adalah handoff untuk AI berikutnya. Fokus pencarian adalah pasangan data mikrotremor/HVSR dengan Vs30, profil Vs, MASW, SPAC, CPT/q-CPT, atau metadata lokasi di Indonesia. File di bawah ini adalah salinan mentah; jangan menimpa file `raw/` ketika melakukan ekstraksi atau normalisasi.

Corpus luar Indonesia dan laporan lanjutannya tersedia di [`datasets_global/README.md`](../datasets_global/README.md).

## Ringkasan cepat

- Repo awal `geoimaging/mhvsr-vs30` sudah diaudit dan diambil ke workspace. Isinya terutama notebook inferensi dan model terlatih; belum ada pipeline training, split spasial, evaluasi eksternal, data contract, atau manifest label.
- Ada **15 source folder lokal** (`source_01`–`source_15`). Sesi 1 (01–08): tujuh arsip ZIP Mendeley/GitHub dan satu DOCX supplementary Springer. Sesi 2 (09–15, 16 Sep 2026): GitHub tutorial HVSR Yogyakarta, Figshare MASW Indonesia Timur, Mendeley Petobo/Upper Semarang/UNDIP, GitHub Jakarta Basin (raw broadband + model Vs 3-D), Figshare Palu.
- Saat ini folder dataset berisi **1.284 file** (sekitar **1,88 GB**, termasuk `SHA256SUMS.txt` per source 09–15, tidak menghitung README ini).
- Kandidat baru paling bernilai dari sesi 2: **source_14 Jakarta** (raw 3C broadband 100 Hz + model Vs dari ambient-noise tomography, yaitu label dari dispersi, bukan dari HVSR yang sama), **source_09 Yogyakarta** (raw MiniSEED 2000 Hz + `.hv` + Vs30 inversi + koordinat, 16 site), **source_10 MASW Pacitan/Lombok/Banda/Ambon** (57 Vs30 MASW berkoordinat; pasangan HVSR harus dicari), dan **source_11 Petobo** (raw GCF + field sheet berkoordinat).
- Kandidat terkuat untuk supervised learning adalah **Meulaboh** (raw waveform + koordinat + q-CPT/Vs appendices) dan **Kaligarang** (raw/HV/model/koordinat). Keduanya tetap memerlukan pemeriksaan apakah label Vs benar-benar independen dari HVSR.
- **Medan** adalah tabel tabular penting: supplementary menyebut 198 site MASW Vs30 pada Table 14 dan 202 site HVSR pada Table 16. Belum diekstrak ke CSV; pasangan site harus direkonsiliasi.
- Telomoyo, Demak, North Central Java, dan Gonoharjo adalah raw/pretraining/QC material; inventaris publiknya tidak menyertakan label Vs30 independen.
- Atlas Vs30 nasional adalah raster proxy/weak label atau covariate, bukan ground truth HVSR.

### Catatan teknis file lokal

- Semua ZIP asli dipertahankan di masing-masing `raw/`; hasil unzip berada di `raw/extracted/`.
- Nama/folder asli tidak dinormalisasi agar provenance tetap terlacak.
- Tidak ada kredensial, paywall, atau bypass CAPTCHA yang digunakan. Percobaan browser otomatis terhenti karena environment melaporkan `privileged native pipe bridge is not available; browser-client is not trusted`; unduhan yang berhasil berasal dari URL publik langsung/API.

## Jejak pencarian dan keputusan metodologis

**Sesi 2, kanal yang ditambahkan:** Figshare API (`api.figshare.com/v2/articles/search`), Mendeley Data search API (`data.mendeley.com/api/research-data/search?query=` karena `page=0` → HTTP 500; mulai dari `page=1`), Mendeley public API per dataset (tanpa `?version=`, dengan User-Agent curl), DataCite REST API (`api.datacite.org/dois?query=…&resource-type-id=dataset`), Europe PMC search + `/{PMCID}/supplementaryFiles` (bypass halaman PMC yang memakai JS challenge), GitHub `gh search repos/code`, ArcGIS Online `sharing/rest/search`, Hugging Face datasets API, Kaggle list API, Springer article HTML (ESM + data availability), Crossref. Zenodo REST API mengembalikan HTTP 400/504 berulang pada sesi ini; hasil Zenodo hanya dari query pertama (tidak ada record Indonesia yang relevan untuk Vs30 teknik).


Portal/kanal yang diperiksa: GitHub dan raw GitHub, Mendeley Data public API, Springer static supplementary, UGM/ITB/ITS/UPI/ITERA repositories, GARUDA, BMKG, Geomate, AIP, DOI/Crossref landing pages, dan pencarian snowball dari referensi paper. Query mencakup `Indonesia microtremor Vs30`, `HVSR MASW Vs30`, `site response`, `SPAC`, `q-CPT`, `shear wave velocity`, nama kota/provinsi, serta variasi Bahasa Indonesia.

Aturan yang harus dipertahankan AI berikutnya:

1. Jangan melatih target Vs30 dari `.model`/Dinver/HVSR inversion lalu mengklaim ground truth; simpan sebagai `derived_label` dengan `label_provenance`.
2. Gunakan split berdasarkan **site/study/geography**, bukan random window/record; semua channel/window dari satu site harus berada pada split yang sama.
3. Pisahkan raw waveform, HV curve, tabular Vs30, raster proxy, dan label hasil inversi dalam schema berbeda.
4. Untuk Meulaboh, mulai dari GL1–GL20 dan buat crosswalk q-CPT ↔ MiniSEED ↔ Appendix E/G. Untuk Kaligarang, selesaikan crosswalk station name sebelum menghitung Vs30.
5. Untuk Medan, ekstrak Table 14 dan Table 16 ke CSV dengan sumber tabel/nomor baris; periksa apakah site ID identik sebelum pairing. Jangan mengasumsikan 198 MASW dan ~202 HVSR semuanya colocated.
6. Audit notebook repo sebelum training: perbaiki pembentukan nama output berbasis `pathlib`, cek scaler skewness yang salah, tambah validasi schema/OOD, uncertainty, dan evaluasi eksternal.
7. Jadikan Atlas hanya sebagai covariate/weak label. Uji korelasi dengan data independen dan dokumentasikan lisensi.
8. Kontak lanjutan yang paling bernilai: UGM Opak 452-point, BMKG/Serang, South Tangerang MASW+HVSR, Bengkulu CPT+microtremor, dan penulis Meulaboh/Kaligarang.

## Struktur output yang disarankan

Jangan mengubah raw. Buat folder baru seperti `processed/`, `manifests/`, dan `labels/` dengan kolom minimal:

`study_id, site_id, latitude, longitude, waveform_path, hv_path, qc_status, sampling_rate_hz, duration_s, f0_hz, A0, vs30_mps, vs30_source, label_provenance, independent_measurement, source_doi, license, split_group`.

Hanya baris dengan `independent_measurement=true` yang boleh masuk evaluasi utama. Baris pseudo-label tetap boleh dipakai untuk pretraining/ablation, tetapi harus dilaporkan terpisah.
